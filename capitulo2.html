Resumo do Capítulo 2: Estruturando Páginas Web com HTML

Introdução: O que é HTML?

HTML é uma das três linguagens mais importantes para o desenvolvimento frontend, junto com CSS e JavaScript. O HTML é responsável por definir a estrutura e a semântica de uma página web. Ele funciona por meio de elementos, que são as "tags" que usamos para marcar o conteúdo.

Versões do HTML

O HTML foi criado por Tim Berners-Lee em 1989 no CERN. A primeira versão saiu em 1992 sem número de versão. O HTML 4.0 foi lançado em 1997 e foi importante porque introduziu o suporte ao CSS. Depois veio o XHTML 1.0, que reformulou o HTML seguindo as regras mais rígidas do XML, exigindo que atributos fossem em minúscula e tivessem sempre um valor. O HTML5 foi lançado em 2014 e é a versão atual que usamos hoje. O HTML5 é mantido como um "Living Standard" pela WHATWG e W3C, o que significa que recebe atualizações contínuas sem precisar de novos números de versão.

Elementos e Atributos

Os elementos HTML definem os componentes de uma página. Cada elemento é composto por uma tag de abertura (como <h1>) e uma tag de fechamento (como </h1>). O texto ou conteúdo fica entre essas duas tags. Os atributos são informações adicionais que você passa para um elemento. Eles ficam dentro da tag de abertura e têm a forma nome="valor". Por exemplo, na tag <a href="url">, o "href" é o atributo e "url" é o valor.

Estrutura Básica de um Documento HTML

Um arquivo HTML é um documento de texto comum com a extensão .html. A estrutura básica começa com <!DOCTYPE html> para declarar que é HTML5. Depois vem a tag <html> que envolve todo o conteúdo. Dentro dela tem a tag <head>, que contém informações que não aparecem na página, como o título (dentro de <title>) e metadados. Por fim, vem a tag <body>, que contém todo o conteúdo visível da página.

Títulos, Parágrafos e Formatação de Texto

Existem seis níveis de títulos em HTML: <h1> é o mais importante e <h6> é o menos importante. Os navegadores exibem os títulos em tamanhos diferentes. Para parágrafos, usamos a tag <p>. O HTML oferece várias formas de formatar texto. A tag <strong> marca texto em negrito com importância semântica, enquanto <b> também deixa em negrito mas sem essa importância. A tag <em> marca texto em itálico com ênfase semântica, e <i> deixa em itálico sem a ênfase. Também existem <sup> para sobrescrito (como em expoentes) e <sub> para subscrito (como em fórmulas químicas). A tag <br /> cria quebras de linha. Para citações, use <blockquote> para citações longas, <q> para citações curtas, e <cite> para referências de fonte. Abreviações e acrônimos usam <abbr>, e definições de termos usam <dfn>.

Criando Listas

Existem três tipos de listas em HTML. Listas ordenadas (numeradas) usam <ol> com <li> para cada item. Listas não ordenadas (com bolinhas) usam <ul> com <li> para cada item. Listas de definição usam <dl>, com <dt> para o termo e <dd> para a definição. Você também pode colocar listas dentro de listas, criando listas aninhadas, que o navegador indenta automaticamente.

Definindo Links

Existem três tipos de links. Links externos levam você para outros sites e usam a URL completa como href. Links relativos levam você para outras páginas no mesmo site e usam apenas o caminho relativo, sem o domínio. Links internos pulam para outro lugar na mesma página usando âncoras, que são marcadas com o atributo id. Para criar um link interno, você coloca # seguido do id no href. É importante que o texto do link seja significativo, como "Clique aqui para mais informações" em vez de apenas "Clique aqui", porque isso ajuda na acessibilidade e usabilidade.

Incluindo Imagens

Para adicionar imagens, usamos a tag <img>, que é uma tag vazia (não tem conteúdo dentro). O atributo src especifica o caminho da imagem, geralmente um caminho relativo para uma pasta de imagens no seu projeto. O atributo alt é muito importante porque fornece um texto alternativo que aparece se a imagem não carregar, e também ajuda leitores de tela para usuários com deficiência visual e motores de busca a entender o que está na imagem. Desde o HTML5, você pode adicionar legendas às imagens usando <figure> como elemento pai e <figcaption> para a legenda.

Estruturando Dados em Tabelas

Tabelas são boas para exibir dados organizados em linhas e colunas. A tag <table> cria a tabela, <tr> cria uma linha, <td> cria uma célula de dados, e <th> cria uma célula de cabeçalho. Para tabelas grandes, você pode usar <thead> para a seção de cabeçalhos, <tbody> para o corpo da tabela, e <tfoot> para o rodapé. Isso ajuda na acessibilidade e permite estilizar essas seções com CSS. Se você quer que uma célula ocupe mais de uma coluna, use o atributo colspan. Se quer que ocupe mais de uma linha, use rowspan.

Definindo Formulários

Formulários são usados para coletar dados do usuário. Você usa a tag <form> para criar o formulário. Dentro dela, pode usar <fieldset> para agrupar campos relacionados de forma significativa. Para criar campos de entrada, use a tag <input> com diferentes valores de type: "text" para texto, "password" para senhas, "email" para emails, "radio" para botões de seleção única, "checkbox" para caixas de seleção múltipla. Use <select> e <option> para criar listas suspensas. Use <textarea> para campos de texto maior. A tag <label> adiciona rótulos aos campos e melhora a acessibilidade. O atributo action do <form> especifica para onde os dados serão enviados, e o atributo method especifica como (GET ou POST). Cada campo precisa de um atributo name para que os dados sejam enviados corretamente.

Conceitos Adicionais Importantes

Elementos de bloco começam em uma nova linha e ocupam toda a largura disponível. Exemplos incluem <p>, <div>, <h1> e <table>. Elementos inline ocupam apenas o espaço necessário e ficam na mesma linha. Exemplos incluem <a>, <strong>, <em> e <img>. A tag <div> agrupa elementos como bloco, enquanto <span> agrupa elementos inline. Ambas são usadas quando você quer criar componentes personalizados que não têm uma tag específica. Alguns caracteres especiais como < e > precisam ser escapados usando códigos HTML: < se escreve como &lt; e > se escreve como &gt;. O atributo id identifica um elemento de forma única na página e é importante para links internos e para trabalhar com CSS. O atributo class agrupa elementos em categorias para estilização com CSS. Você pode adicionar comentários no HTML usando <!-- comentário -->. Além de imagens, você pode incluir arquivos multimídia como áudio e vídeo. Dentro da tag <head>, você pode adicionar metadados com a tag <meta> para informações sobre a página, como palavras-chave para SEO. O HTML5 introduziu elementos semânticos como <header> (cabeçalho), <footer> (rodapé), <nav> (navegação), <article> (artigos), <aside> (informações laterais) e <section> (seções) para descrever melhor a estrutura da página. Dentro do <head>, você pode incluir arquivos CSS com <link> e arquivos JavaScript com <script>.

Resumo das Regras Fundamentais

HTML é uma linguagem de marcação que define a estrutura e semântica de páginas web usando elementos. Cada elemento tem uma tag de abertura e uma tag de fechamento. Informações adicionais são passadas através de atributos que ficam na tag de abertura. Alguns elementos podem conter outros elementos e texto, mas elementos vazios não podem. Páginas web são documentos de texto simples com extensão .html. Existem muitos elementos HTML disponíveis, sendo os mais importantes os títulos, parágrafos, listas, links, imagens, tabelas e formulários.
