Capítulo 3 — Projetando Páginas Web com CSS

Resumo de Estudos

O que é CSS?

CSS é a linguagem responsável pela aparência visual das páginas web. Ele separa o conteúdo estrutural (HTML) da apresentação visual.

Estrutura de uma Regra CSS


seletor {
    propriedade: valor;
}
  • Seletor: define o elemento.
  • Propriedade: o que será alterado.
  • Valor: como será aplicado.

Formas de Inserir CSS

CSS Externo

Arquivo separado conectado com a tag link.

CSS Interno

Usa a tag style dentro do head.

CSS Inline

Aplicado diretamente na tag HTML.

Seletores CSS

  • Seletor de tipo: p, h1, section
  • Classe: .classe
  • ID: #identificador
  • Seletores combinados

Modelo de Caixa (Box Model)

  • Content — conteúdo do elemento
  • Padding — espaço interno
  • Border — borda
  • Margin — espaço externo

Cores e Texto

Formas de definir cores:

  • Nomes de cores
  • Hexadecimal
  • RGB e RGBA

Propriedades importantes: font-family, font-size e text-align.

Sistemas de Layout

Position

  • static
  • relative
  • absolute
  • fixed
  • sticky

Flexbox

Sistema de layout unidimensional usado para alinhar elementos em linha ou coluna.

Grid Layout

Sistema bidimensional baseado em linhas e colunas, ideal para layouts complexos.
